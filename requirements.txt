What each library is used for in your project:

ultralytics: Provides the YOLOv8 object detector and the integrated ByteTrack algorithm.

opencv-python-headless: Reads video frames, draws bounding boxes, tripwires, and ID labels. Using the headless version ensures it runs without GUI display errors on web servers like Streamlit Cloud.

streamlit: Powers your web-based interactive dashboard to upload videos, adjust sliders, and view the live count.

numpy: Handles array manipulations and bounding box coordinate calculations.

tabulate: Formats the terminal accuracy and evaluation tables.

matplotlib: Generates the track duration histogram used in your robustness analysis.
